# DronCpp


1. Взять модель Landscape Mountains (https://www.unrealengine.com/en-US/blog/new-on-marketplace-landscape-mountains) стандартный пример из UE4
2. Добавить туда любую 3D модель на ваш вкус, например, автомобиль
3. Добавить камеру , разрешение 640 на 480 пикселей
4. Через Blueprints запрограммировать движение камеры по окружности вокруг объекта на расстоянии примерно 300 м, камера на каждом кадре смотрит на объект
5. Любым удобным способом запрограммировать движение объекта так, чтобы траектория его движения не вышла за пределы съемки
6. Через Blueprints запрограммировать сохранение кадров форматом jpg или png с частотой 1 раз в секунду


Developed with Unreal Engine 5
